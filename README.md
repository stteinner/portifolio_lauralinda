# Portfólio pessoal

Portfólio desenvolvido com React, TypeScript, Vite e CSS. O projeto apresenta uma introdução, informações sobre a trajetória de estudos, habilidades, projeto em destaque e contato pelo GitHub.

## Tecnologias

- React
- TypeScript
- Vite
- CSS
- Lucide React

## Executar localmente

1. Instale o [Node.js](https://nodejs.org/).
2. Clone este repositório.
3. No terminal, entre na pasta do projeto e execute:

```bash
npm install
npm run dev
```

4. Abra no navegador o endereço local exibido pelo Vite.

## Gerar versão de produção

```bash
npm run build
npm run preview
```

A pasta gerada para publicação é `dist`.

## Publicar na Vercel

Importe este repositório na Vercel. O comando de build é `npm run build` e a pasta de saída é `dist`.

## Personalização

Antes de divulgar o portfólio, revise a apresentação pessoal e adicione seus dados reais, projetos concluídos e links profissionais. Não mantenha informações de exemplo.
